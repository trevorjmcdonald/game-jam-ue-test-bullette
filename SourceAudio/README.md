# Source audio

Source files for the sounds in `/Game/Audio`. Each one is imported to the matching folder with the same name: `Music/MUS_Run.wav` becomes `/Game/Audio/Music/MUS_Run`. All of it is CC0.

## Music: Juhani Junkala, "Retro Game Music Pack" (CC0)

From [5 Chiptunes (Action)](https://opengameart.org/content/5-chiptunes-action) on OpenGameArt. The tracks loop seamlessly.

| File | Original |
|---|---|
| `Music/MUS_MainMenu.wav` | Title Screen |
| `Music/MUS_Run.wav` | Level 1 |
